## What could still make the purchase wrong

- **Wrong motor variant delivered** (48 V GIM listing, J4310 V1.2 vs V1.1, 7.4 V STS3215): check the listing against M1_BENCH_ARM.md before paying.
- **The GIM6010 CAN protocol** couldn't be read here (the manual is blocked). If it had no impedance/torque mode, control would fall back to position mode with torque limits: workable for the bench, weaker for learning policies. Ask the seller for the protocol document.
- **DM-J4310 output-bearing moment rating** (≈ 0.9 N·m dynamic at the wrist pitch): ask the seller.
- **Printed parts:** if C1 shows KX slip under rated torque, or M1 shows hand sag far above the chain estimate, the fix is in printed parts and fasteners (stiffer shells, PETG-CF / ASA, bolted joints), not in the motors.

# Pip v4: hardware R&D, operating model and plan

**Scope:** the robot's **physical design** (mechanical, electrical, industrial design, simulation, cost). The AI stack comes later.

**Concept:** [V4_CONCEPT.md](V4_CONCEPT.md). **Live numbers:** [rnd/SCORECARD.md](rnd/SCORECARD.md). **History:** [RND_LOG.md](RND_LOG.md).

**Owner's brief (2026-11-25):** Claude runs the development. Iterate over long periods, innovate, change course when the evidence says so, and don't stop at the first "done". More compute → a better robot.

---

## 1. Operating model: a continuous engineering loop

Each scheduled run (and any interactive session) does one **loop**:

1. **Sync:** `git pull`; read the scorecard, the work queue (§4), and the last few log entries.
2. **Critique.** Ask what the single highest-leverage thing is right now. Candidates:
   - the **weakest scorecard metric**
   - the **biggest unretired risk**
   - the **next thing a build needs**
   - a **better idea** that could beat the current design (look for precedent first)
3. **Do the work** with real tools:
   - build123d CAD
   - MuJoCo twin and analyses (`python -m rnd.run_all`)
   - Blender renders
   - web research with sources
   - parallel subagents for independent research, where useful
4. **Measure:** regenerate the reports and update the scorecard. **A change that makes the scorecard worse is reverted unless the log explains why it's worth it.**
5. **Decide:** update the decision table (§3). Decisions **can be reversed**; record why. Edit the queue freely: add, split, reorder or delete.
6. **Record:** commit and push to `claude/robot-dog-p2s-printer-j4esie`, and add a log entry: what, numbers before → after, files, open questions.
7. **Tell the owner:** a short summary every run. A **digest** (renders + scorecard delta + decisions taken) every ~4 runs, or after any major change. Digests **don't block**; work continues.

**External review budget (owner, 2026-11-26):** Gemini 4 Neon (`rnd/external_review.py`) costs ≈ $1.67 per run. Use it **at most once per day**, and only after a significant batch of fixes. The script refuses a second run within 24 h.

**Cadence (owner, 2026-11-26):** runs every 30 minutes (two hourly scheduled tasks at :10 and :40, since one task can't run more often than hourly).

**Two tracks (owner, 2026-11-26):** hardware (this plan) and **software** ([SOFTWARE_PLAN.md](SOFTWARE_PLAN.md), starting with the bench arm). Runs **alternate**: the :10 run does hardware, the :40 run does software, unless one track is blocked.

**Efficiency rules (owner, 2026-11-26: "make more progress per run"):**
1. **One concrete deliverable per run**, picked in under 2 minutes from the queue top. No re-deliberating settled decisions.
2. **Incremental checks only.** Run the checks that cover what changed:
   - CAD of the arm → integration, spacing, assembly_seq
   - masses → spacing/workspace via `run_all --quick`

   The slow full set (FEA, dynamic sim, print plan, Monte Carlos, full `run_all`) runs only when its inputs changed, and at most every 4th run.
3. **Long jobs go to the background** while the next step proceeds. Run independent checks in parallel processes.
4. **Commit early** (at least once per run), with a short log entry (5 lines max) and a short owner summary (3 lines max).
5. **Don't chase the last 1 %:** stop when the deliverable passes its check. Queue polish separately.

**The loop never "finishes".** When the queue is empty, the next run starts with a fresh critique of the whole design and writes a new queue: a stronger design, cheaper parts, easier assembly, better looks.

**Guardrails:**
- No purchases, PRs or AI-stack work.
- Every part ≤ 256 mm (P2S).
- Every actuator in a joint cartridge.
- Numbers come with sources or are marked `ESTIMATE`.
- Keep `rnd/params.py` the single source of truth.
- Only the owner decides to **buy hardware**. Milestones below end with a buy/no-buy question.

# KX joint interface v1: analysis (auto-generated by `python -m rnd.run_all`)

**Architecture.** A cartridge carries **torque only**. Its output face locks into a **hub** that turns in the bone's own bearing pair, and the motor housing is held by a **torque pin** in a radial slot (precedent: shaft-mounted gearboxes with a torque arm). Bending, axial and crash loads go through the bone's bearings, never through the printed interface or the motor's bearing.

**Seat.** 3 hardened balls on the cartridge; each sits on **two hardened dowel pins** in the hub (a ball on two rods: Maxwell coupling). A **breech-lock collar** with ramped teeth pulls the faces together, and a **spring stack** sets the preload (it rotates on a PTFE thrust washer).

**Design sweep (loop 2):** contact angle β 30° → 20° and balls Ø8 → Ø10 on Ø5 pins (KX74). The same 1.15× peak slip margin then needs 160 N of preload instead of 250 N. Twist effort drops from 4.2–6.3 to 2.1–2.7 N·m, and peak contact stress drops from 4,227 to ~3,550 MPa.

## Reading the numbers

- **Printed grooves fail.** A steel ball pressed into a printed V-groove at working load reaches several times PETG's yield. It would dent and creep, and the joint would lose its zero. **Dowel-pin grooves are the baseline**, not a fallback. Six Ø3–4 mm hardened pins plus three G25 balls per interface cost well under $1.
- **Slip torque is a feature.** With a defined preload the seat is a **ball-detent overload clutch**: it holds the actuator's peak torque, and beyond that it lets go before a printed bone breaks. It re-seats at the same position (kinematic). A slip past one ball pitch re-indexes by 120°, so the joint must re-home: v1 adds a magnet index in every hub for a Hall check (cartridge electronics item).
- **Ball-on-pin contact stress** stays under the bearing-steel static limit even at the actuators' absolute peak torque.
- **The twist effort is jar-lid territory (about 2–3 N·m).** That is why the collar has two thumb tabs and the ramp gets a smear of grease. Self-locking holds because the 6° ramp is below the friction angle (8.5° greased).
- **Socket bearings:** 61808 / 61805 thin-section pairs (~$2 each, ESTIMATE). Safety ≥ 2 everywhere under the conservative load case.

Assumptions marked ESTIMATE in `rnd/kx_check.py`; contact stresses use the R_eff = √(Ra·Rb) point-contact approximation.

# Cable routing across the joints (generated by `python -m rnd.harness`)

The question: can the arm bundle cross every joint over its full range without a slip ring? Two methods are checked per
joint (all cable data ESTIMATE until the datasheets are in hand):

1. **Torsion through the hollow shaft.** The bundle runs along the axis and twists. A torsion-rated robot cable allows
   about ±360°/m (TORSION_DEG_PER_M), so the free axial length L must be ≥ (range / 2) / 360 m.
2. **Clock-spring spiral** (as in a car's steering-wheel clock spring). The bundle lies in a flat spiral in an annular
   cavity r_in … r_out around the axis. Rotation winds or unwinds it, so the cable bends but never twists. The capacity
   for a spiral of length S is Δθ = S·(1/r_in − 1/r_out) rad (wound tight on r_in ↔ loose on r_out). It needs
   r_in ≥ the bend radius of the stiffest cable (10 × OD for continuous flex) and a cavity of the bundle's height.

The joint ranges come from the twin (rnd/twin.py JR). The free lengths and the cavity sizes are read off the CAD
(module dimensions; ESTIMATE ± 10 mm).

**Joints the arm bundle can cross: 6/6 with D12** (CSI flat-flex through the wrist + slim Ø2.2 USB from the forearm); 2/6 with the camera's stock Ø3.8 USB cable.

  - a MIPI-CSI camera on a thin FFC through both wrist joints
  - a CSI→USB (UVC) bridge board on the forearm

# Shoulder balancer (auto-generated by `python -m rnd.run_all`)

Zero-free-length cable-spring balancer. Pulley A sits 45–65 mm above the pitch axis in a slot; pin B sits on a lever on the pitch shaft 30 mm from the axis. A cable runs B → A → (2:1 tackle) → a caged die spring in the torso, giving τ = k·a·b·sin(pitch) at every angle. Precedent: the Anglepoise lamp, Herder's spring balancers, French & Widden cable balancers.

**Spring (A9, loop 40):** ISO 10243 light-load (green) die spring, Ø25 hole / Ø12.5 rod, L0 115 mm (ESTIMATE rate ≈ 12 N/mm; pick the catalogue rate ≥ 4·k). The loop-7 compression spring (3 N/mm over 85 mm, ≈ 11 J) would have been ≈ 210 mm long and never fitted the 135 mm cage (external review finding 10). The moving pulley halves the travel; die springs store the energy in about half the length. Cable: B → U604 pulley A → U604 moving pulley on the spring plate → anchor screw on the cage.
**Detach hazard (A9):** with the arm off, the spring torque K·sin(pitch) is unopposed. Detach and attach only with the arm hanging (pitch 0, where the torque is zero), with the **park pin** in: a Ø6 pin through the bracket wall into a hole in the balancer disc at pitch 0. The pitch motor holds the shaft as well while powered.
**Failure mode:** with the cable cut, the arm is simply unbalanced; the pitch motor still holds it (see the workspace margins without the spring in spring.md).

## E-stop behaviour (A5, loop 40: external review finding 6)
- **Two-channel mushrooms (torso back, base rear).** Channel 1 opens the contactor coil loop directly (hardware, no software in the path). Channel 2 tells the Pi and the sensor nodes, which command a controlled stop. Motor power drops; logic stays up to log and report.
- **Stop category:** loop 39 had a *safe stop 1* with a 0.5 s capacitor hold-up. A capacitor delay is not a dependable timer, so the **default is now category 0** (power cut at once). The arms go limp; the balancer and belt friction slow the fall (≈ 0.3 s to the stop at the hanging pose; a 1 kg payload is released by the gripper's own back-drive). SS1 can return later with a rated delay relay.
- **Everything that moves is downstream of the contactor:** loop 39 fed the 12 V servo converter from the logic branch, so the wrists, grippers and head kept power in an e-stop. It now sits after the contactor.
- **Pre-charge:** 13 motor drivers put several mF on the bus. Closing straight onto them welds contactor tips over time, so a 22 Ω resistor charges the bus for 0.5 s first (the reset button starts a timer relay).
- **Regen clamp:** the GIM6010 drivers are rated to 28 V, and a full pack is 25.2 V. A decelerating or back-driven arm pumps the bus up when the BMS won't take charge (full pack) or after the contactor opens. A 26.5 V shunt regulator (comparator, MOSFET, 10 Ω 50 W aluminium resistor) plus a 33 V TVS hold the bus. **On the M1 bench this is mandatory:** a bench power supply can't sink current at all.
- **Watchdog:** the Pi's control loop toggles a watchdog input on the e-stop relay board; if the loop stalls for 50 ms the contactor opens (SW2).
- **Torso:** the lift pawl is spring-applied, so it drops in and the torso holds (A15 reviews the pawl itself).
- Not a certified safety function. The bench arm runs inside a marked keep-out zone until SW2 is measured.

# Hand positioning accuracy budget (auto-generated by `python -m rnd.accuracy`)

Static hand error at 0.6 m reach, root-sum-square of the per-joint angular errors × lever arm, plus bone and
mast bending. Error sources (ESTIMATEs, refine with the coupon/bench tests):
- motor encoder resolution (GIM: 14-bit on the motor, ×reduction)
- planetary backlash inside the GIM (≈ 0.2° at its output, typical for small planetary QDDs) ÷ belt ratio
- belt backlash/tooth play (HTD 5M ≈ 0.15° at the joint) and belt stretch under the holding load
- KX seat repeatability (≈ 0.01° kinematic; negligible), bone bending (rnd/bones.py), mast sway (rnd/mast.py)

servo loop removes backlash and belt stretch from the static error. What remains is the encoder (±0.05° after
calibration) and the unmeasured bending.

# Pip v4: software track (owner, 2026-11-26)

**Strategy (the speed lever is data):** don't train from scratch. Start from a **pretrained open policy**, **co-train with

```python
def _arc_slot(r, hw, az, half, h):
    """Annular slot of half-width hw at radius r, ±half degrees about azimuth az (round ends), height h, from z = 0."""
    from build123d import Polygon, extrude
    ring = Cylinder(r + hw, h, align=MIN) - Cylinder(r - hw, h, align=MIN)
    keep = [(0.0, 0.0)] + [(3 * r * math.cos(math.radians(az + 180 + a)), 3 * r * math.sin(math.radians(az + 180 + a))) for a in range(-(180 - half), 180 - half + 1, 5)]
    gap = extrude(Polygon(*keep, align=None), h)                      # the solid sector the slot must NOT cut (around az + 180)
    ring -= gap
    for a in (-half, half):
        t = math.radians(az + a)
        ring += Pos(r * math.cos(t), r * math.sin(t), 0) * Cylinder(hw, h, align=MIN)
    return ring
```

```python
def fin_ray(top_z: float, tip_z: float, face_x: float, depth: float, thick: float = 26.0, facing: int = +1, ribs: int = 5) -> Part:
    """Fin-ray finger: triangle in the x-z plane. Vertical contact face at x = face_x (facing ±x toward the object); the back
    face slopes from depth at the top to the tip. Thin TPU walls + cross ribs make the contact face wrap around the
    object (Festo FinRay; UMI gripper). Printed in TPU 95A. thickness along y."""
    from build123d import Polygon, extrude
    s = -facing                                                    # back side direction
    pts = [(face_x, top_z), (face_x + s * depth, top_z), (face_x, tip_z)]
    outer = extrude(Polygon(*pts, align=None), thick)
    w = 1.6
    inner_pts = [(face_x + s * w, top_z - w), (face_x + s * (depth - w * 2.2), top_z - w), (face_x + s * w, tip_z + w * 3.2)]
    inner = extrude(Polygon(*inner_pts, align=None), thick)
    shell = outer - inner
    for k in range(1, ribs + 1):
        z = top_z + (tip_z - top_z) * k / (ribs + 1)
        shell += (Pos((face_x + face_x + s * depth) / 2, z, thick / 2) * Rot(0, 0, s * 12) * Box(depth * 1.2, 1.2, thick)) & inner
    res = Rot(90, 0, 0) * shell                     # extrusion direction depends on the polygon winding: re-centre on y = 0
    bb = res.bounding_box()
    return Pos(0, -(bb.min.Y + bb.max.Y) / 2, 0) * res
```

```python
"""KX joint interface v1: a kinematic seat plus a spring-preloaded breech-lock collar.

Precedents: Maxwell 3-groove kinematic couplings built from a ball on two rods (precision
fixturing); breech-lock and PL lens mounts (twist collar, sprung preload); shaft-mounted
gear reducers held by a torque arm (SEW, e-bike hub motors).

**Load path (v1).** A cartridge carries **torque only**.
- Its output face (male) locks into a **hub** in the driven bone. The hub turns in the
  bone's own bearings, which carry every bending and axial load.
- The motor housing is kept from spinning by a **torque pin** sitting in a radial slot.
  The slot leaves radial and axial freedom, so the cartridge is never over-constrained.

**Parts.**
    male   (on the cartridge output): flange with 3 hardened balls (pressed in) and 3 bayonet lugs
    hub    (in the bone): 3 grooves, each made of two steel dowel pins laid radially
           (a ball on two rods). This is not a printed V-groove: the Hertz contact stress
           on plastic would be about 5x PETG yield (see docs/rnd/kx.md).
    collar (captive on the hub): internal ramped teeth. A 35° twist puts the teeth behind
           the lugs. A spring stack between the collar lip and the hub step sets the preload.
    retainer: screwed under the hub; it keeps the collar and spring captive.

Coordinates in **mated** position: the hub's top face is z = 0; the male arrives from +Z with
its mating face down; the ball centres sit at z = z_ball. All lengths are mm.
"""
from __future__ import annotations

import math
from dataclasses import dataclass

from build123d import Align, Box, Cylinder, Part, Pos, Rot, Sphere, Axis, chamfer

MIN = (Align.CENTER, Align.CENTER, Align.MIN)


@dataclass(frozen=True)
class KX:
    name: str
    od: float           # male flange OD
    face_t: float       # male flange thickness
    ball_d: float       # hardened steel ball (G25 chrome steel)
    ball_pcd: float
    pin_d: float        # hardened dowel pins forming each groove
    pin_len: float
    lug_reach: float    # lug radial extension beyond od/2
    lug_w: float        # lug tangential width
    lug_t: float        # lug axial thickness (at the back of the flange)
    tooth_t: float      # collar tooth axial thickness
    preload_n: float    # design preload from the spring stack
    beta_deg: float = 20.0      # ball-to-pin contact normal from the face plane. Lower = less lift-out per N·m
                                # -> less preload -> easier twist (sweep in docs/rnd/kx.md: 30° needed 250 N, 20° needs 160 N)
    pin_proud: float = 0.6      # pins stand this far above the hub face (sets the face gap); male face has reliefs
    ball_recess: float = 0.0    # D15: ball centre this far inside the male face (snap past the equator + retaining compound)
    twist_deg: float = 35.0
    ramp_deg: float = 5.0       # below the friction angle (8.5° lubed, 14° dry PETG) -> self-locking. Loop 40: 6 → 5° (twist p95 sat at the 3 N·m rule with D15)
    clearance: float = 0.3
    spring_t: float = 2.0       # D15 (loop 40): gap between the hub step and the collar lip; 6 coil springs Ø4 sit in 3 mm
                                # pockets in the step (installed 5 mm). Was 1.2 mm with a 1 mm-wide annulus: no real spring fits
    stroke: float = 1.0         # teeth sit this far below the lug backs: the last ~14° of twist lifts
                                # the collar by `stroke`, compressing the spring -> preload (k ≈ preload / 1.5 mm)

    # ---- derived geometry ----
    @property
    def r_ball(self): return self.ball_pcd / 2

    @property
    def pin_z(self): return -self.pin_d / 2 + self.pin_proud

    @property
    def z_ball(self):
        return self.pin_z + (self.ball_d + self.pin_d) / 2 * math.sin(math.radians(self.beta_deg))

    @property
    def pin_sep(self):                                         # pin centre spacing
        return (self.ball_d + self.pin_d) * math.cos(math.radians(self.beta_deg))

    @property
    def gap(self): return self.z_ball - self.ball_recess        # male face height above hub face

    @property
    def lug_back_z(self): return self.gap + self.face_t        # back of the male flange / lugs (mated)

    @property
    def r_collar_in(self): return self.od / 2 + self.lug_reach + self.clearance + 0.4

    @property
    def r_hub(self): return self.r_collar_in - 0.3

    @property
    def r_collar_out(self): return self.r_collar_in + 5.5

    @property
    def r_tooth_in(self): return self.od / 2 + self.clearance + 0.2   # teeth must clear the flange while inserting


# Cartridge M (GIM6010-8, DM-J4310). Cartridge S (STS3215).
# D15 (loop 40, external review finding 2): pins 1 mm prouder and balls 1 mm deeper in the male face (captured past
# their equator), so the face gap is unchanged.
KX74 = KX("KX74", od=74, face_t=7, ball_d=10.0, ball_pcd=58, pin_d=5.0, pin_len=14,
          lug_reach=6, lug_w=14, lug_t=3.0, tooth_t=2.4, preload_n=160, pin_proud=1.6, ball_recess=1.0)
# DM-J4310 (Ø57, 7 N·m peak): KX74 is oversized for the wrist and upper-arm yaw (loop 4 mass pass)
KX56 = KX("KX56", od=56, face_t=6, ball_d=8.0, ball_pcd=43, pin_d=4.0, pin_len=11,
          lug_reach=5, lug_w=11, lug_t=2.5, tooth_t=2.2, preload_n=140, pin_proud=1.4, ball_recess=0.8)
KX44 = KX("KX44", od=44, face_t=5, ball_d=6.0, ball_pcd=31, pin_d=3.0, pin_len=8,
          lug_reach=4, lug_w=9, lug_t=2.5, tooth_t=2.0, preload_n=80, pin_proud=1.2, ball_recess=0.6)
BALL_ANG = (90, 210, 330)
LUG_ANG = (30, 150, 270)
HUB_STEP = 6.0       # hub keeps r_hub from z=0 to -HUB_STEP, then steps in by STEP_IN
STEP_IN = 5.5        # D15: 1.5 → 5.5, room for the spring pockets
SPRING_D, SPRING_POCKET = 4.4, 3.0
SPRING_ANG = (0, 60, 120, 180, 240, 300)   # between the pin pairs (90/210/330) and the retainer screws (30/150/270)
LIP_T = 2.0


def _at(r, ang):
    return Pos(r * math.cos(math.radians(ang)), r * math.sin(math.radians(ang)), 0)


def male(kx: KX, bore: float = 0.0) -> Part:
    """Male face in its own frame: z in [0, face_t], mating face at z = 0 (normal -Z), lugs at the back."""
    p = Cylinder(kx.od / 2, kx.face_t, align=MIN)
    p = chamfer(p.edges().group_by(Axis.Z)[0], 0.6)       # lead-in on the mating edge
    for a in LUG_ANG:
        # back face ramped like the collar teeth -> face contact, not an edge
        p += _at(kx.od / 2 + kx.lug_reach / 2 - 1, a) * Rot(0, 0, a) * Pos(0, 0, kx.face_t) * Rot(-kx.ramp_deg, 0, 0) * \
            Box(kx.lug_reach + 2, kx.lug_w, kx.lug_t, align=(Align.CENTER, Align.CENTER, Align.MAX))
    for a in BALL_ANG:                                    # D15: pockets past the equator (ball centre ball_recess inside the face)
        p -= _at(kx.r_ball, a) * Pos(0, 0, kx.ball_recess) * Sphere(kx.ball_d / 2 - 0.05)
        # relief so the proud pins clear the face
        p -= _at(kx.r_ball, a) * Rot(0, 0, a) * Box(kx.pin_len + 2, kx.pin_sep + kx.pin_d + 2, 2 * (kx.pin_proud + 0.5))
    if bore:
        p -= Cylinder(bore / 2, 100)
    return p


def balls(kx: KX) -> Part:
    out = None
    for a in BALL_ANG:
        b = _at(kx.r_ball, a) * Sphere(kx.ball_d / 2)
        out = b if out is None else out + b
    return out


def _pin(kx: KX, a: float, side: int) -> Part:
    """One dowel pin, radial, offset tangentially by ±pin_sep/2 (mated frame)."""
    return Rot(0, 0, a) * Pos(kx.r_ball, side * kx.pin_sep / 2, kx.pin_z) * Rot(0, 90, 0) * \
        Cylinder(kx.pin_d / 2, kx.pin_len)


def pins(kx: KX) -> Part:
    out = None
    for a in BALL_ANG:
        for s in (-1, 1):
            out = _pin(kx, a, s) if out is None else out + _pin(kx, a, s)
    return out


def hub(kx: KX, depth: float = None, bore: float = 0.0, screws: bool = True) -> Part:
    """Female hub (top of a bone's driven member). Face at z = 0, body down to -depth."""
    depth = depth or HUB_STEP + LIP_T + kx.spring_t + 1.0
    p = Pos(0, 0, -HUB_STEP) * Cylinder(kx.r_hub, HUB_STEP, align=MIN)
    p += Pos(0, 0, -depth) * Cylinder(kx.r_hub - STEP_IN, depth - HUB_STEP, align=MIN)
    for a in BALL_ANG:
        # pin bores (pressed in radially from the outside; the access hole is the same size)
        for s in (-1, 1):
            p -= Rot(0, 0, a) * Pos((kx.r_ball - kx.pin_len / 2 + kx.r_hub + 2) / 2, s * kx.pin_sep / 2, kx.pin_z) * \
                Rot(0, 90, 0) * Cylinder(kx.pin_d / 2, kx.r_hub + 2 - (kx.r_ball - kx.pin_len / 2))
        # relief channel: exposes the pin contact lines; deeper slot clears the ball's bottom
        p -= Rot(0, 0, a) * Pos(kx.r_ball, 0, 0) * Box(kx.pin_len + 1, kx.pin_sep, -kx.pin_z * 2)
        p -= Rot(0, 0, a) * Pos(kx.r_ball, 0, 0) * Box(kx.ball_d, kx.pin_sep - kx.pin_d, (kx.ball_d / 2 - kx.z_ball + 0.8) * 2)
    # 3 × M3 holes for the retainer (screwed version only)
    for a in LUG_ANG if screws else ():
        p -= _at(kx.r_hub - STEP_IN - 3.5, a) * Pos(0, 0, -depth) * Cylinder(1.25, 8, align=MIN)
    # D15: 6 spring pockets in the step face (springs push the collar lip down → teeth onto the lug backs → preload)
    for a in SPRING_ANG:
        p -= _at(kx.r_hub - STEP_IN / 2, a) * Pos(0, 0, -HUB_STEP) * Cylinder(SPRING_D / 2, SPRING_POCKET, align=MIN)
    if bore:
        p -= Cylinder(bore / 2, 100)
    return p


def retainer(kx: KX, depth: float = None) -> Part:
    depth = depth or HUB_STEP + LIP_T + kx.spring_t + 1.0
    r = Pos(0, 0, -depth - 2) * (Cylinder(kx.r_collar_in + 1.5, 2, align=MIN) - Cylinder(kx.r_hub - STEP_IN - 7, 2, align=MIN))
    for a in LUG_ANG:
        r -= _at(kx.r_hub - STEP_IN - 3.5, a) * Pos(0, 0, -depth - 2) * Cylinder(1.7, 2, align=MIN)
    return r


def hub_pip(kx: KX, depth: float = None, bore: float = 0.0) -> Part:
    """D15 (loop 40): the socket as built = hub + screwed retainer (3 × M3 into heat-set inserts), shown as one solid
    for geometry checks. The name is kept for callers.

    Loop 10's print-in-place version (hub + retainer in one print, collar printed around it, pauses for the pins and the
    spring) is retired for the first build (external review finding 2): its 1 mm spring annulus held no real spring,
    the pauses were listed in the wrong order (the lip layer prints before the pin layer: the hub is printed face-up),
    and the hub step had to bridge over a loose spring. It stays a coupon experiment (C1) for a later build-time cut.

    Assembly: press the 6 dowel pins in radially; put 6 springs in the step pockets; slide the collar up from below;
    screw the retainer on. ≈ 8 min per socket (ESTIMATE)."""
    depth = depth or HUB_STEP + LIP_T + kx.spring_t + 1.0
    core = Pos(0, 0, -depth - 2) * Cylinder(kx.r_hub - STEP_IN - 7, 2, align=MIN)
    return hub(kx, depth, bore, screws=True) + retainer(kx, depth) + core - (Cylinder(bore / 2, 400) if bore else Pos(0, 0, 1000) * Cylinder(1, 1))


def spring(kx: KX) -> Part:
    """D15: the 6 coil springs (Ø4, installed 5 mm: 3 mm in the pockets + the 2 mm gap to the collar lip)."""
    out = None
    for a in SPRING_ANG:
        c = _at(kx.r_hub - STEP_IN / 2, a) * Pos(0, 0, -HUB_STEP - kx.spring_t) * Cylinder(1.9, kx.spring_t + SPRING_POCKET - 0.2, align=MIN)
        out = c if out is None else out + c
    return out


def collar(kx: KX, locked: bool = True) -> Part:
    """Collar in the mated frame. Unlocked = rotated +twist_deg (the teeth sit between the lugs)."""
    z0 = -HUB_STEP - kx.spring_t - LIP_T
    top = kx.lug_back_z + kx.tooth_t
    c = Pos(0, 0, z0) * (Cylinder(kx.r_collar_out, top - z0, align=MIN) - Cylinder(kx.r_collar_in, top - z0, align=MIN))
    c += Pos(0, 0, z0) * (Cylinder(kx.r_collar_in + 0.1, LIP_T, align=MIN) - Cylinder(kx.r_hub - STEP_IN + 0.3, LIP_T, align=MIN))
    reach = kx.r_collar_in - kx.r_tooth_in
    for a in LUG_ANG:
        # tooth underside slopes by ramp_deg: its leading edge (toward the lug) is higher
        t = Pos(0, 0, kx.lug_back_z - kx.stroke) * Rot(-kx.ramp_deg, 0, 0) * Box(reach + 1.0, kx.lug_w - 2, kx.tooth_t, align=MIN)
        c += Rot(0, 0, a) * Pos(kx.r_tooth_in + (reach + 1.0) / 2, 0, 0) * t
    for k in range(24):                                   # grip flutes
        c -= _at(kx.r_collar_out + 0.5, k * 15) * Pos(0, 0, z0) * Cylinder(1.1, top - z0, align=MIN)
    for a in (LUG_ANG[0] + 60, LUG_ANG[1] + 60):          # two thumb tabs for leverage
        c += Rot(0, 0, a) * Pos(kx.r_collar_out + 3, 0, z0) * Box(9, 10, top - z0 - 2, align=MIN)
    return c if locked else Rot(0, 0, kx.twist_deg) * c


def male_mated(kx: KX, bore: float = 0.0) -> Part:
    return Pos(0, 0, kx.gap) * male(kx, bore)


def balls_mated(kx: KX) -> Part:
    return Pos(0, 0, kx.gap) * balls(kx)
```

```python
"""Printed HTD 5M pulleys and the small-pulley hub (KX74 socket + straddle-mounted pulley on 2 bearings).

Load path: the cartridge (torque only) locks into the hub's KX74 face; belt pull goes into two 61804 bearings
(20×32×7) that sit in the bone walls on both sides of the pulley. Tooth form is an approximation of HTD 5M
(round groove, depth 2.06 mm, pitch-line offset 0.57 mm): print a test pulley and check it against a real belt.
"""
from __future__ import annotations

import math

from build123d import Align, Box, Cylinder, Part, Pos, Rot

from .kx import KX74, hub_pip as hub

MIN = (Align.CENTER, Align.CENTER, Align.MIN)
PITCH, PLD, DEPTH, GROOVE_R = 5.0, 0.5715, 2.06, 1.60
BRG_6004 = dict(d=20.0, D=32.0, B=7.0)   # 61804 thin-section (C0 ≈ 2.3 kN, ESTIMATE); name kept for callers


def pulley(teeth: int, width: float = 16.0, flange: bool = True, bore: float = 0.0) -> Part:
    pd = teeth * PITCH / math.pi
    od = pd - 2 * PLD
    p = Cylinder(od / 2, width, align=MIN)
    rc = od / 2 - DEPTH + GROOVE_R
    for k in range(teeth):
        a = 2 * math.pi * k / teeth
        p -= Pos(rc * math.cos(a), rc * math.sin(a), 0) * Cylinder(GROOVE_R, width, align=MIN)
        p -= Pos((rc + GROOVE_R) * math.cos(a), (rc + GROOVE_R) * math.sin(a), 0) * Rot(0, 0, math.degrees(a)) * Box(1.6, 2 * GROOVE_R, width, align=MIN)
    if flange:
        for z in (-1.2, width):
            p += Pos(0, 0, z) * Cylinder(od / 2 + 2.0, 1.2, align=MIN)
    if bore:
        p -= Cylinder(bore / 2, 200)
    return p


def small_hub(teeth: int = 20, belt_w: float = 15.0) -> Part:
    """KX74 hub face on top (z ≥ 0 side is the cartridge), then a Ø20 journal, pulley, Ø20 journal (straddle)."""
    w = belt_w + 1.0
    b = BRG_6004
    top_j = Pos(0, 0, -b["B"] - 1) * Cylinder(b["d"] / 2, b["B"] + 1, align=MIN)          # journal under the hub
    pul = Pos(0, 0, -b["B"] - 1 - 1.2 - w) * pulley(teeth, w)
    bot_j = Pos(0, 0, -b["B"] - 1 - 1.2 - w - 1.2 - b["B"]) * Cylinder(b["d"] / 2, b["B"], align=MIN)
    h = Pos(0, 0, -0.0) * hub(KX74)
    hz = h.bounding_box().min.Z
    return Pos(0, 0, 0) * h + Pos(0, 0, hz) * (top_j + pul + bot_j) - Pos(0, 0, hz - 200) * Cylinder(4.2, 400, align=MIN)


def bearings_dummy(z_top: float, belt_w: float = 15.0) -> Part:
    b = BRG_6004
    w = belt_w + 1.0
    ring = Cylinder(b["D"] / 2, b["B"], align=MIN) - Cylinder(b["d"] / 2, b["B"], align=MIN)
    z1 = z_top - b["B"] - 1
    z2 = z1 - 1.2 - w - 1.2 - b["B"]
    return Pos(0, 0, z1) * ring + Pos(0, 0, z2) * ring


def belt_loop(pd_small: float, pd_big: float, centre: float, width: float = 15.0, t: float = 3.6) -> Part:
    """Belt as a solid band around two pitch circles (for renders): hull of two discs minus the inner hull."""
    def hull(r1, r2):
        a = math.asin((r2 - r1) / centre)
        L = math.hypot(centre, 0)
        body = Cylinder(r1, width, align=MIN) + Pos(centre, 0, 0) * Cylinder(r2, width, align=MIN)
        # quadrilateral between tangent points
        mid = (r1 + r2) / 2
        body += Pos(centre / 2, 0, 0) * Box(centre, 2 * mid * math.cos(a) * 0.999, width, align=MIN)
        return body
    return hull(pd_small / 2 + t / 2, pd_big / 2 + t / 2) - hull(pd_small / 2 - t / 2, pd_big / 2 - t / 2)


ECC = dict(od=38.0, e=1.0, t=7.0)   # printed eccentric bushing around each 61804: rotate to tension the belt, 1 lock screw


def eccentric_bushing() -> Part:
    """Bearing seat Ø32 offset by e inside an Ø38 ring with a lock tab: ±1 mm centre-distance adjustment (≈ ±2 mm belt
    length) without slots or a tensioning screw. ~5 min per stage instead of ~15 (ESTIMATE)."""
    e = ECC
    r = Cylinder(e["od"] / 2, e["t"], align=MIN) - Pos(e["e"], 0, 0) * Cylinder(BRG_6004["D"] / 2, e["t"], align=MIN)
    r += Pos(e["od"] / 2 + 3, 0, 0) * (Box(10, 8, 2.5, align=MIN) - Pos(2, 0, 0) * Cylinder(1.7, 3, align=MIN))
    return r

# Loop 40 (R14): split big pulleys. A printed pulley slides onto its Ø40 tube between the walls and drives it through a
# double-D (two flats, 36 mm across): the tube still passes the 61808/6708 bores, so it can be inserted from one side.
DD_AF = 36.0


def dd_prism(h: float, af: float = DD_AF, r: float = 20.0) -> Part:
    """Double-D section (Ø2r with two flats af apart, flats normal to X) extruded along Z from z = 0."""
    return Cylinder(r, h, align=(Align.CENTER, Align.CENTER, Align.MIN)) & Box(af, 2 * r + 2, h, align=(Align.CENTER, Align.CENTER, Align.MIN))


def dd_flats(z0: float, h: float, af: float = DD_AF, r: float = 20.0) -> Part:
    """What to subtract from a Ø2r tube (axis Z) to cut the two flats over z0 … z0 + h."""
    return Pos(0, 0, z0) * (Cylinder(r + 1, h, align=(Align.CENTER, Align.CENTER, Align.MIN)) - dd_prism(h, af, r))


def split_pulley(teeth: int, width: float = 16.0, flange: bool = False, af: float = DD_AF, web: bool = True) -> Part:
    """Printed HTD 5M pulley with a double-D bore (+0.4 mm), lightened to a 5 mm web when it is large."""
    p = pulley(teeth, width, flange=flange) - dd_prism(width + 10, af + 0.4, 20.2).translate((0, 0, -5))
    r_rim = teeth * PITCH / math.pi / 2 - PLD - DEPTH - 5.0
    if web and r_rim > 34:

    return p
```

```python
- Balancer plane, outboard of the bracket: a lever on the pitch shaft carries anchor pin B (30 mm); pulley A rides in a vertical slot
  45–65 mm above the axis; the cable runs back over A into a horizontal cage with a 2.7 N/mm compression spring (rnd/balancer.py).
- Outboard end of the shaft: the **KX-V ferrule** (3" sanitary profile, 3 dowels): the arm clamps on here with a V-band.

Y_F = -78.0                # KX74 hub face of the pitch cartridge (loop 39: -58 → -78 for the 64 mm D13 v2 stack; can 1.3 mm clear of the lift carriage)

WALL_T = 6.0

Y_FER = 2.0                # ferrule spigot start; the detach plane (flat face) is at Y_FER + 18 = 20

def _rot_y(p):            # build along Z, then lay along +Y
    return Rot(-90, 0, 0) * p


def ferrule(male: bool = True) -> Part:
    """3"-style sanitary ferrule flange (printed). Profile ESTIMATE until checked against a real clamp."""
    f = FERRULE
    t_flat = 3.0
    p = Cylinder(f["od"] / 2, t_flat, align=MIN)
    # 20° taper on the back face (where the clamp wedges): approximated by a cone frustum
    from build123d import Cone
    p += Pos(0, 0, t_flat) * Cone(f["od"] / 2, f["od"] / 2 - (f["t"] - t_flat) * math.tan(math.radians(90 - f["taper_deg"])) * 0.35,
                                  f["t"] - t_flat, align=MIN)
    p += Pos(0, 0, f["t"]) * Cylinder(32, 10, align=MIN)                   # spigot toward the shaft / roll link
    for k in range(3):
        a = math.radians(90 + 120 * k)
        hole = Pos(f["dowel_r"] * math.cos(a), f["dowel_r"] * math.sin(a), 0) * Cylinder(3.0 - (0.05 if male else -0.05), 12, align=MIN)
        p -= hole
    return p - Cylinder(15, 40, align=MIN)


def pitch_shaft() -> Part:
    """Ø40 hollow shaft with the balancer disc (pin B) and the ferrule on the outboard end. Loop 40 (R14): the 60T pulley
    is a separate part (pitch_pulley) on a double-D, so the shaft goes in from outboard through W_OUT's 61808, the pulley
    and W_IN's 61808."""
    L = Y_FER - (W_IN - 4)
    from .belt_stage import dd_flats
    tube = Cylinder(20, L, align=MIN) - Cylinder(15, L, align=MIN)
    tube -= dd_flats(Y_BELT - 8.5 - (W_IN - 4), 17)                        # loop 40 (R14): double-D under the split 60T pulley
    s = Pos(0, W_IN - 4, 0) * _rot_y(tube)
    disc = Cylinder(25, 5, align=MIN) - Cylinder(15, 5, align=MIN)
    disc += Pos(0, -17, 0) * Box(14, 26, 5, align=MIN)                      # lever
    disc += Pos(0, -30, 0) * Cylinder(3, 9, align=MIN)                      # pin B, 30 mm from the axis (points down when the arm hangs)
    s += Pos(0, Y_BAL - 2.5, 0) * _rot_y(disc)
    s += Pos(0, Y_FER + 18, 0) * Rot(90, 0, 0) * ferrule(male=False)       # flat face outboard at the detach plane
    return s

    xs, zs = 190.0, 150.0
    x0 = -BELT_C / 2 - 10
    walls = None
    for y in (W_IN, W_OUT):

        w -= Pos(0, y, 0) * Rot(-90, 0, 0) * Cylinder(26, wall_t + 1)                  # 61808 seat (OD 52)
        w -= Pos(-BELT_C, y, 0) * Rot(-90, 0, 0) * Cylinder(19.1, wall_t + 1)          # eccentric-bushing seat (Ø38) around the small hub's 61804
        # lightening (loop 8 diet): keep ≥ 10 mm of material around both bearing seats and along the back web

            w -= Pos(cx, y, cz) * Rot(-90, 0, 0) * fillet(Box(lx, lz, wall_t + 1).edges().filter_by(Axis.Z), 5)

    p += post
```

```python
gives τ_s = K·sin(pitch) (zero-free-length spring + cable, the Anglepoise / Herder gravity-balancing principle).
When the elbow bends or the arm rolls sideways, the arm's centre of mass moves and the balance drifts.

This samples the joint space (MuJoCo twin, static gravity torques), fits K, and reports the motor torque left over.

    """Static pitch-joint torque (N·m, at the joint) for random right-arm poses. Returns (pitch_rad, torque)."""
    m, dat = _model(d)
    rng = np.random.default_rng(seed)
    jid = {j: mujoco.mj_name2id(m, mujoco.mjtObj.mjOBJ_JOINT, f"{j}_r") for j in ("pitch", "roll", "yaw", "elbow", "wpitch", "wroll")}

        t_out[i] = dat.qfrc_bias[m.jnt_dofadr[jid["pitch"]]]

        mujoco.mj_forward(m, dat)

            if j == "pitch":

    return out


def fit_balancer(p, t):
    """Least-squares K for τ_s = K·sin(p) (spring cancels the arm's own weight)."""
    s = np.sin(p)
    return float(np.dot(s, t) / np.dot(s, s))
```

```python
"""Shoulder-pitch gravity balancer: zero-free-length spring via cable (Anglepoise / Herder / French & Widden principle).

Geometry: pulley A sits on the torso a metres *above* the pitch axis O. Anchor B is a pin on the pitch joint's
big pulley, b metres from O along the arm (below O when the arm hangs). A cable runs B → over A → down into the
torso to a caged spring (A9: through a 2:1 tackle into a die spring). The cage is designed so the spring is at its free length when the cable length
A–B would be zero, so the spring force is k·|AB| ("zero free length").
Then the torque about O is k·a·b·sin(pitch) exactly, for any pitch: the same law the workspace study assumed.
K is adjusted by sliding pulley A along a slot (a changes), never by pre-tension (which would break the law).
"""
from __future__ import annotations

import math

import numpy as np

from .params import BASELINE, Design

A_NOM, A_RANGE = 0.050, (0.045, 0.065)   # m, pulley A height above O (slot). |a-b| ≥ 15 mm so pin B clears pulley A at pitch 180°
B = 0.030                                # m, anchor pin radius on the balancer lever (loop 7 CAD: 40 → 30 so B clears A when the arm points up)
R_PULLEY = 0.0055                        # m, pulley A radius: U604ZZ grooved bearing pulley (A9: was an ungrooved Ø12 printed pulley)
CABLE_BREAK_N = 2000.0                   # 2 mm Dyneema/UHMWPE braid (ESTIMATE; typical 150–250 daN)
SPRING_SAFE_STROKE = 0.105               # m, cage stroke available (kept for the score signature)
# A9 (loop 40, external review finding 10): the loop-7 spring could not exist. Zero free length makes the spring deflect by
# the whole A–B span (up to a + b = 80 mm) at k = 3 N/mm: it stores ≈ 11 J, and a Ø25 compression spring that does that
# without overstress is ≈ 210 mm long (25-coil, d 3.2 mm) — it never fitted the 135 mm cage. Fix: a 2:1 tackle (the cable
# runs B → A → a moving pulley on the spring plate → anchored), so the spring sees half the travel at four times the rate,
# and a stock ISO 10243 die spring (rectangular wire, high energy density) fits the cage.
TACKLE = 2
CAGE_L = 0.135
DIE = dict(name="ISO 10243 light-load (green) die spring, Ø25 hole / Ø12.5 rod, L0 115 mm (ESTIMATE rate ≈ 12 N/mm; pick the catalogue rate ≥ 4·k)",
           L0=0.115, max_frac=0.40)        # long-life deflection limit for light-load die springs (≈ 40 % of L0, ESTIMATE)


def spring_rate(K: float, a: float = A_NOM, b: float = B) -> float:
    return K / (a * b)


def torque(theta: float, k: float, a: float, b: float, rp: float = R_PULLEY) -> float:
    """Exact spring torque about O (N·m) with a finite pulley at A. theta = pitch from hanging (rad)."""
    Bp = np.array([b * math.sin(theta), -b * math.cos(theta)])          # anchor (x forward, z up)
    Ap = np.array([0.0, a])
    d = Ap - Bp
    L = float(np.linalg.norm(d))
    # tangent point on pulley A: the cable leaves B toward the pulley's near side; length to tangency
    l_t = math.sqrt(max(L * L - rp * rp, 1e-12))
    ang = math.atan2(d[1], d[0]) + math.asin(rp / L) * (1 if Bp[0] >= 0 else -1)
    u = np.array([math.cos(ang), math.sin(ang)])
    ext = l_t + rp * (math.pi / 2)          # wrap ≈ quarter turn into the torso (constant part folded into the cage)
    F = k * (ext - rp * math.pi / 2)        # cage zeroed so F = k·(free span length)

    ks = TACKLE ** 2 * k                                   # spring rate behind the tackle
```

```python
"""Safety supervisor (S1-safety, SW2). Sits between any policy/teleop and the motor drivers; independent of the policy.

Every control cycle it takes the wanted joint targets and returns what may be sent, or a stop:
1. **Watchdog:** if `tick()` isn't called for WATCHDOG_S (50 ms), the next call returns STOP and the e-stop relay's
   watchdog input stops toggling (electrical.md A5: the contactor opens in hardware as well).
2. **Joint limits:** targets clamped to [lower + margin, upper − margin] (sw/description/joints.json, from the twin).
3. **Velocity limit:** target steps limited to v_max·dt per joint (bench default 1.5 rad/s at the joint).
4. **Torque limit:** feed-forward torque clamped to the joint's rated torque (peak only with `allow_peak`).
5. **Workspace:** the hand (forward kinematics from the bench twin) must stay inside a box above the table; a target
   that leaves it is rejected and the last good target is held.
6. **Feedback sanity:** a measured position outside the limits by more than 5°, a motor error flag, or a temperature
   over TEMP_C (55 °C, the PETG/ASA can rule, thermal.md A6) → STOP.
7. **E-stop input:** latched; needs `reset()` with the button released.
Every decision is counted, so a session log shows how often the policy was overruled.
"""
from __future__ import annotations

import json
import math
import time
from dataclasses import dataclass, field
from pathlib import Path

import numpy as np

WATCHDOG_S, TEMP_C = 0.050, 55.0
DESC = Path(__file__).resolve().parent / "description" / "joints.json"


@dataclass
class Verdict:
    stop: bool
    q: np.ndarray | None
    t_ff: np.ndarray | None
    reasons: list = field(default_factory=list)


class Supervisor:
    def __init__(self, v_max=1.5, margin_deg=3.0, ws_lo=(0.10, -0.45, 0.76), ws_hi=(0.80, 0.45, 1.35), clock=time.monotonic, fk=None):
        J = json.loads(DESC.read_text())
        self.names = [j["name"] for j in J]
        m = math.radians(margin_deg)
        self.lo = np.array([j["lower"] for j in J]) + m
        self.hi = np.array([j["upper"] for j in J]) - m
        self.rated = np.array([j["rated_nm"] for j in J])
        self.peak = np.array([j["peak_nm"] for j in J])
        self.v_max, self.clock, self.fk = v_max, clock, fk
        self.ws_lo, self.ws_hi = np.array(ws_lo), np.array(ws_hi)
        self.last_tick = None
        self.last_q = None
        self.estop = False
        self.counts = {}

    def _count(self, k):
        self.counts[k] = self.counts.get(k, 0) + 1

    def tick(self):
        self.last_tick = self.clock()

    def press_estop(self):
        self.estop = True

    def reset(self, q_meas):
        self.estop = False
        self.last_q = np.clip(np.asarray(q_meas, float), self.lo, self.hi)
        self.tick()

    def check(self, q_want, t_ff=None, q_meas=None, err=None, temp=None, dt=1 / 500, allow_peak=False) -> Verdict:
        now = self.clock()
        why = []
        if self.estop:
            why.append("e-stop latched")
        if self.last_tick is None or now - self.last_tick > WATCHDOG_S:
            why.append("watchdog")
        if q_meas is not None and (np.any(q_meas < self.lo - math.radians(8)) or np.any(q_meas > self.hi + math.radians(8))):
            why.append("measured position outside limits")
        if err is not None and np.any(np.asarray(err) != 0):
            why.append("motor error flag")
        if temp is not None and np.nanmax(np.asarray(temp, float)) > TEMP_C:
            why.append("over temperature")
        if why:
            for w in why:
                self._count(w)
            return Verdict(True, None, None, why)
        q = np.clip(np.asarray(q_want, float), self.lo, self.hi)
        if np.any(q != q_want):
            self._count("joint limit clamp")
        if self.last_q is None:
            self.last_q = q if q_meas is None else np.asarray(q_meas, float)
        step = self.v_max * dt
        q2 = self.last_q + np.clip(q - self.last_q, -step, step)
        if np.any(np.abs(q2 - q) > 1e-12):
            self._count("velocity clamp")
        if self.fk is not None:
            p = self.fk(q2)
            if np.any(p < self.ws_lo) or np.any(p > self.ws_hi):
                self._count("workspace reject")
                q2 = self.last_q
        lim = self.peak if allow_peak else self.rated
        t = None if t_ff is None else np.clip(np.asarray(t_ff, float), -lim, lim)
        if t_ff is not None and np.any(t != t_ff):
            self._count("torque clamp")
        self.last_q = q2
        return Verdict(False, q2, t, [])
```

```python
"""MIT-mode CAN frames (S1). The Damiao DM-J4310 speaks this format ("MIT mode"); it is the MIT Mini Cheetah layout.

Command (8 bytes): position 16 bit | velocity 12 | kp 12 | kd 12 | torque 12, each a linear map of a float range.
Feedback (8 bytes): byte 0 = id (low nibble) | error (high nibble); position 16 | velocity 12 | torque 12; MOS °C; rotor °C.
Special frames: enable FF×7 FC, disable FF×7 FD, set zero FF×7 FE.

The float ranges (P_MAX, V_MAX, T_MAX) are set per motor in Damiao's config tool; the defaults below are the J4310
factory values as commonly documented (ESTIMATE: read them back from the motor on day 1 and put them in joints.json).
The GIM6010-8 (SteadyWin SDC104) protocol is not implemented: its manual could not be fetched from here. `gim.py`
holds the interface to fill from the manual when the motors arrive.
"""
from __future__ import annotations

from dataclasses import dataclass

ENABLE = bytes([0xFF] * 7 + [0xFC])
DISABLE = bytes([0xFF] * 7 + [0xFD])
ZERO = bytes([0xFF] * 7 + [0xFE])


@dataclass(frozen=True)
class Ranges:
    p_max: float = 12.5     # rad
    v_max: float = 30.0     # rad/s
    t_max: float = 10.0     # N·m
    kp_max: float = 500.0
    kd_max: float = 5.0


def f2u(x, lo, hi, bits):
    x = min(max(x, lo), hi)
    return int(round((x - lo) / (hi - lo) * ((1 << bits) - 1)))


def u2f(u, lo, hi, bits):
    return u / ((1 << bits) - 1) * (hi - lo) + lo


def pack_cmd(p, v, kp, kd, t, r: Ranges = Ranges()) -> bytes:
    P = f2u(p, -r.p_max, r.p_max, 16)
    V = f2u(v, -r.v_max, r.v_max, 12)
    KP = f2u(kp, 0, r.kp_max, 12)
    KD = f2u(kd, 0, r.kd_max, 12)
    T = f2u(t, -r.t_max, r.t_max, 12)
    return bytes([P >> 8, P & 0xFF, V >> 4, ((V & 0xF) << 4) | (KP >> 8), KP & 0xFF, KD >> 4, ((KD & 0xF) << 4) | (T >> 8), T & 0xFF])


def unpack_cmd(b: bytes, r: Ranges = Ranges()):
    P = (b[0] << 8) | b[1]
    V = (b[2] << 4) | (b[3] >> 4)
    KP = ((b[3] & 0xF) << 8) | b[4]
    KD = (b[5] << 4) | (b[6] >> 4)
    T = ((b[6] & 0xF) << 8) | b[7]
    return (u2f(P, -r.p_max, r.p_max, 16), u2f(V, -r.v_max, r.v_max, 12), u2f(KP, 0, r.kp_max, 12),
            u2f(KD, 0, r.kd_max, 12), u2f(T, -r.t_max, r.t_max, 12))


def pack_feedback(mid, err, p, v, t, t_mos=30, t_rotor=30, r: Ranges = Ranges()) -> bytes:
    """For the virtual bus / tests: what a motor would send back."""
    P = f2u(p, -r.p_max, r.p_max, 16)
    V = f2u(v, -r.v_max, r.v_max, 12)
    T = f2u(t, -r.t_max, r.t_max, 12)
    return bytes([(err << 4) | (mid & 0xF), P >> 8, P & 0xFF, V >> 4, ((V & 0xF) << 4) | (T >> 8), T & 0xFF, t_mos, t_rotor])


def unpack_feedback(b: bytes, r: Ranges = Ranges()):
    mid, err = b[0] & 0xF, b[0] >> 4
    P = (b[1] << 8) | b[2]
    V = (b[3] << 4) | (b[4] >> 4)
    T = ((b[4] & 0xF) << 8) | b[5]
    return dict(id=mid, err=err, p=u2f(P, -r.p_max, r.p_max, 16), v=u2f(V, -r.v_max, r.v_max, 12),
                t=u2f(T, -r.t_max, r.t_max, 12), t_mos=b[6], t_rotor=b[7])
```
